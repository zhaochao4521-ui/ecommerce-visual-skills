# 文案创作与审校

主标题回答本屏主要购买问题；辅助句解释对象、条件或机制；短卖点对应画面局部；规格说明负责准确。层级之间分工，不重复抢同一句信息。

- 标题长短随内容变化，朗读检查顺畅；不统一八字、十六字或固定句式。
- 用户要多版时，通常给少量真正不同的表达角度，并用一句话说明侧重；用户只要结果时省略解释。
- 情绪标题可以口语化；机制标题优先动作与结果；规格和套餐用准确名称、件数及包含物，避免只用昵称。
- 默认保留用户确认文案。字数与画面冲突先换行或调整文字区，确需改写时保留意思、条件和参数，不静默删字。
- 不把旧图中的价格、赠品、证书、年份、性能或促销门槛带入新产品。
- 图片中的倒置、飞溅、使用动作不是性能检测依据。材质、安全、时长、耐受等结论采用当前资料中可核对的依据。
- 中英文一致，单位与型号完整，断行不拆否定词和数值条件；英文、标号、图标有信息作用才使用。

交付前核对：表达对象、事实出处、适用条件、前后矛盾、重复信息、标题与画面是否相互支持。没有投放数据时称为创意方向，不称为已验证有效。
