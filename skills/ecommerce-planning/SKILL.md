# 电商策划与文案

根据用户本次目标、产品资料和已确认方案，交付能直接使用的文案与内容策划。本技能独立运行，不需要个人案例库、特定品牌或其他技能。

## 先判断范围

在内部快速确定目标成果，不要求用户背编号或选择流程：

|需求|读取与执行|
|---|---|
|改标题、写辅文案、审文案|读[文案方法](references/copy.md)，只完成指定内容|
|提炼卖点、排序、主图内容、详情页Demo|读[策划方法](references/planning.md)，按当前范围组织|
|客户方案、PDF、小红书内容|读[交付与渠道](references/delivery.md)，提供对应成果|

简单问题直接回答。复合任务只组合必要方法。已有资料不重问，只有真正阻碍结果的缺口才集中询问；不为纯文案追问画幅或镜头参数。

## 工作流程

1. 锁定当前产品型号、结构、版本、颜色、材质与功能依据；区分确认事实、用户原话、历史信息和策划假设。历史产品的参数、赠品、销量、认证和促销不自动沿用。
2. 根据使用者、购买者、使用事件和渠道，确定用户最需要的购买理由。将卖点转成“需求或顾虑→已确认事实→可感收益→支持画面或证据”。
3. 按信息任务安排主图或详情页顺序。每屏一个主要问题，平级细节可以合并；不固定张数、屏数或统一标题字数。
4. 逐屏Demo按需要包含主要任务、标题备选、一句辅文案、卖点短句、画面指引和相邻页关系。用户指定格式时沿用。需要视觉提案时按项目提供少量有区别的方向，不强制固定配色套数或字体数量。
5. 对照产品事实审校文字，保留单位、条件、否定词和重要参数。改动已确认的策划或文案时说明影响，不为好看虚构功效。
6. 交付用户指定的文本或客户方案。要求实际PDF时，使用当前可用文档工具生成并检查；缺工具时说明实际完成范围，不能把聊天文字称为PDF。

## 优先级与交接

本次明确要求与最新修订 → 当前项目确认事实 → 本项目已确认方向 → 适用的用户偏好 → 本技能默认 → 示例。

只要文案不自动生图。需要图片制作时输出简短交接：当前产品事实、确认文案、每张图的任务、画面方向、文字位置与固定项。对方可以使用独立图片技能或现有制作工具，不依赖任何固定目录或私有技能。小红书文案不等于已发布；没有实际数据不宣称已提高点击或转化。
