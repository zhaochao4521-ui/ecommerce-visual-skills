# 电商图片制作与提示词

先识别交付类型、当前产品与修改范围，再选择最小必要流程。普通问答不强行调用制作；资料足够直接执行，不要求用户记英文名或功能编号。本技能独立运行，不需要私有审美包、案例图片或外部账号。

只读本次相关文件，不先遍历全部参考。外部已有视觉方案时直接落实；缺新方向时用内置视觉判断形成简短方案，不把外部审美技能作为运行前提。

## 执行流程

1. 锁定当前产品版本、轮廓、比例、标识、色款、材质分部、真实部件、数量和配件。区分当前事实、历史内容和创作提案；未知不从相似商品补造。
2. 选择新生成、参考引导重构或沿底图局部编辑。逐张区分产品、人物身份、服装、构图、光色和文字来源；“其他不变”明确底图、修改项与冻结项。
3. 按页面任务安排产品角度、景别、文字净区、色彩职责和受光。复杂人物画面再检查动作、支撑与接触。已经确认的方向不重新探索。
4. 只要提示词时给独立完整的中文文本；要求图片时检查当前可用工具并实际制作。调用宿主工具须遵守其规范；没有工具就说明具体缺口，不把提示词称为已出图。
5. 实际查看输出，核对产品、人物接触、文字、数量、规格对应和真实尺寸。局部修改同时复查目标命中和冻结项，不以整体氛围代替产品正确性。
6. 交用户所需的图片或文本，并说明实际尺寸及确实存在的未解决项。批量任务统一命名和对应关系，简单单图不强加完整资产台账。

## 边界与优先级

本次明确要求与最新修订 → 当前产品事实 → 当前项目已确认方向 → 适用的用户偏好 → 方法建议 → 示例。

只改图不自动重做文案策略；只审图不自动改图；只要提示词不生图。需要策划时可接收任何来源的简报：产品事实、每图任务、确认文案、固定项与输出范围；不依赖指定策划技能。尺寸、人物年龄、风格、人群和配件均按当前项目决定，不把一个类目的偏好套到所有产品。

不承诺像素级不变、指定模型不存在的能力或分层PSD。工具成功不等于质量通过，没有生成或实际查看就不写已验收。
