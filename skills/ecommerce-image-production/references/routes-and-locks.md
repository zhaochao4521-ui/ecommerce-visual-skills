# 路线与产品锁定

## 三种路线

- 新生成：没有需继承的底图或用户明确要全新方案。补齐可见主体、场景和镜头描述；缺真实产品图时只称方向示意。
- 参考引导重构：允许重组机位、画幅、构图或人物站位。各参考分别约束身份、产品、光色等，重构不等于可以改型号或产品比例。
- 沿底图局部编辑：用户要求“其他不变”或只指定一处。明确目标底图、允许区域和冻结内容，不能静默转成整图重构。工具保真能力不足时说明实际限制。

扩图、裁切、等比缩放与重构分开；不能拉伸产品冒充改比例。比例已明确或沿用原图时不重复询问；缺比例确实影响新图制作时集中补问。

## 当前产品合同

只登记本次必要的几项：产品版本、轮廓比例、结构部件、颜色图案标识、材质分区、SKU与数量、配件包含关系。产品照片中的道具不自动成为标配；旧海报中的参数、促销、赠品和日期不自动继承。

整体放大产品不等于拉长杯身、缩小盖子或改机器结构。部件连接与开合方式依据当前资料，无法判断就保留未知。

## 多参考与修改

记录每张图承担什么：编辑底图、产品身份、人脸、姿态、衣服、构图、光影或文字。不能用一个含糊的“整体像参考”覆盖全部决定。

内部保留底图与版本、目标项、冻结项、参考职责、输出画幅和工具限制。修改后回查原合同；候选探索不自动变成已确认版本。
