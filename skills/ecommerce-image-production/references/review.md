# 检查与交付

在目标尺寸及关键放大处实际查看最终文件，完整项目再通看整套。按本次任务核对，不用长清单代替成果。

1. 产品：轮廓、比例、结构、标识、色款、材质分区、部件与附件是否符合当前资料。
2. 接触：手指、握持、支撑、重心、遮挡、倒影与接触影是否可读且合理。
3. 文字：逐字与确认稿比对，数值、单位、条件、SKU配置、日期和包含物是否一致。
4. 视觉：主体焦点、文字净区、光向与材质反应、合成元素受光、系列稳定项与变化是否成立。
5. 文件：实际宽高、比例、数量、命名、完整画面与交付格式是否满足要求。精确像素与比例分开，不能把1:1直接当成某个固定尺寸。
6. 修改：同时检查目标是否命中，以及应保留的产品、人物、构图、文案等是否回归。

分别说明“已生成、已内部检查、用户已确认”的真实状态。只审文字就称文字检查，无法看输出就不能宣称画面通过。不承诺工具不支持的分层文件或精确编辑能力。

实际生图、导出或排版依赖当前宿主工具，本技能不附带模型、API凭据或外部账号。工具不可用时交可完成的提示词或方案，说明具体缺口；涉及外部服务或费用时遵从用户明确的范围。
