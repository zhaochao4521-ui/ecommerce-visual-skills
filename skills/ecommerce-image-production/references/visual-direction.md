# 基本视觉判断

先确定本图任务与需要的感觉，再把感觉转成可见关系，不将“高级、活力、松弛”等词固定对应某种颜色或人群。

1. 焦点：安排第一主体、第二信息与后读细节，比较面积、明暗、色相、边缘、遮挡和清晰度。缩略图检查主次；主体不必永远最大。
2. 色彩：先锁产品本色，再分配背景、服装、道具、标题与强调色的职责。颜色按相邻关系与面积使用；估计色号只作设计建议，不冒充品牌实测标准色。
3. 光线：按用途选择柔窗光、硬斜光、低调侧光或局部灯，写清相对方向、软硬和背景亮度。提亮、改配色、改高光是不同变量，不能混为一项。
4. 材质：金属保留有形状的反射，塑料保留适合表面的高光，玻璃保留透明与边缘，织物保留纹理和阴影。照片观感不能证明材料成分或性能。
5. 构图：先定骨架、景别、前中后景、视线路线与文字净区，再添加元素。道具有具体作用；装饰不能抢产品与必要信息。
6. 系列：统一少量锚点，如光向、文字位置、色彩职责或标签语法；按页面任务变化景别和信息，不把整套做成完全一样的构图。

有参考时实际看相关画面，分开“看见的事实、设计解释、当前建议”。没有图像访问能力时不能声称已经看图。局部问题只给最重要的几处改法，不默认展开整套视觉研究。
