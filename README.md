# 电商策划与图片制作技能

公开版 v1.0.0，2026-10-31。两个技能可分别安装、单独使用，也可以协作。不依赖个人案例库、私有审美技能、特定品牌或外部账号。

|技能|主要能力|调用示例|
|---|---|---|
|电商策划与文案 ecommerce-planning|产品卖点、购买理由、标题与辅文案、主图内容分工、详情页顺序、Demo、客户方案与PDF内容、小红书文案|策划：根据这些已确认卖点，写三组标题和一句辅文案。|
|电商图片制作与提示词 ecommerce-image-production|完整提示词、参考反推、生图与改图、换产品、主图海报、SKU、线稿色稿、人物动作与成图检查|图片：按当前产品写一条独立完整的提示词，暂时不生成。|

## 使用

将需要的完整技能文件夹安装到当前工具支持的技能目录，再选择该技能或直接描述对应需求。支持显式名称的环境可使用 `$ecommerce-planning` 或 `$ecommerce-image-production`。两者均不要求输入编号。

只改文案就处理文案；只要提示词不生成图片；已有视觉方向直接落实；完整新案才展开整套内容。图片版内置基础视觉判断，外部审美指导是可选输入。

实际生成图片、编辑文件、输出PDF需要当前宿主提供相应工具。本包不附带生成模型、API密钥、付费额度或分层PSD生产引擎。

## 文件

`skills/` 中的两个目录是独立安装单元。每个含SKILL.md、agents/openai.yaml和按需加载的references方法。根目录的verify_package.py检查文件完整性和内部引用；manifest.json记录文件SHA256。

## 演示输入

以下是虚构示例：

- 策划：桌面收纳盒，仅确认三分区与可堆叠。请给三个标题方向，每个带一句辅文案；不要虚构尺寸、材料和价格。
- 图片：一只浅灰色矩形三分区收纳盒，位于浅蓝桌面中央，平视，柔和侧光，3:4，上方留白，无文字。只要一条完整提示词。

## 内容范围

仅包含通用工作流和新编写的方法说明。没有附带客户案例、产品原图、个人偏好档案、聊天记录或账号配置。没有把实际素材迁移或文本检查称为重新审美阅读，也不承诺生成结果与商业效果。

## 本地检查

在仓库根目录运行 `python verify_package.py`，仅使用Python标准库，无网络请求。
